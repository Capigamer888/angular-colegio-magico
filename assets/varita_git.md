# 🪄 La Varita Git: Comandos Esenciales para el Colegio Mágico

En tu camino como hechicero del software, Git es tu varita mágica para registrar avances, crear puntos de control y viajar en el tiempo.

---

## ⚡ Los Comandos Básicos de tu Varita

### 1. Consultar el estado del caldero
```bash
git status
```
*Muestra qué archivos has modificado, qué pociones están listas para guardar y cuáles aún no han sido consagradas.*

### 2. Consagrar cambios al área de preparación
```bash
git add .
```
*Prepara todos los archivos modificados para el commit.*

### 3. Registrar el hechizo (Commit)
```bash
git commit -m "feat: completar reto 1 de inicializacion de pociones"
```
*Crea una instantánea inmutable en la historia del repositorio.*

---

## 📜 El Grimorio de Prefijos Mágicos (Conventional Commits)

Utiliza siempre estos prefijos para que el Tribunal entienda tu intención:

* `feat:` Para un nuevo reto completado o nueva funcionalidad (ej. `feat: agregar alerta de toxicidad con @if`).
* `fix:` Para corregir un error o bug en la lógica (ej. `fix: corregir intervalo de tiempo en ngOnDestroy`).
* `docs:` Para cambios en la documentación o la bitácora (ej. `docs: completar bitacora de IA para el PR`).
* `style:` Para mejoras visuales en CSS o espaciado (ej. `style: mejorar auras de colores de las casas`).
* `refactor:` Para limpiar código sin alterar su funcionamiento.

---

## 🚀 Enviar tus hechizos a la nube (GitHub)
```bash
git push origin tu-rama
```
*Lanza tus cambios hacia tu repositorio forkeado en GitHub.*
