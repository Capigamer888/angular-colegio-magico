⏳ El Despertar y Desvanecimiento: Ciclos de Vida (Lifecycle Hooks)

Un componente en Angular es un ser viviente: nace (ngOnInit), muta con nuevas pociones (ngOnChanges) y se desvanece (ngOnDestroy).

💡 Claves Pedagógicas para la Clase

• constructor(): Instancia básica de la clase en memoria. No hagas llamadas HTTP ni configures timers pesados aquí.
• ngOnInit(): Momento sagrado para inicializar datos, llamar APIs o arrancar procesos.
• ngOnChanges(): Se dispara automáticamente cuando una propiedad con {{ '@Input()' }} cambia de valor desde el componente padre.
• ngOnDestroy(): ¡El exorcismo de memoria! Aquí se cancelan suscripciones, WebSockets y clearInterval() para no dejar procesos zombis en el navegador.
