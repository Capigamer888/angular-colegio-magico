🪞 El Vínculo Mágico: Data Binding y [(ngModel)]

La conexión viva entre la lógica de TypeScript (el cerebro) y el HTML del navegador (los sentidos del usuario).

💡 Los 4 Tipos de Data Binding en Angular

1. Interpolación {{ '{{ nombreAprendiz }}' }}: TypeScript ➔ HTML (Muestra texto en pantalla).
2. Property Binding [disabled]="condicion": TypeScript ➔ HTML (Controla propiedades del elemento HTML).
3. Event Binding (click)="hechizo()": HTML ➔ TypeScript (Escucha acciones del usuario).
4. Two-Way Binding [(ngModel)]="variable": ¡Bidireccional! Conocido como "Banana in a box" [()]. Cualquier cambio en el input actualiza TypeScript y viceversa inmediatamente. Requiere importar FormsModule.
