🪄 Encantamientos de Vista: Directivas Modernas ({{ '@if' }}, {{ '@for' }}, [ngClass])

Las directivas son los conjuros que transforman la estructura del DOM y visten a los elementos con auras de estilo.

📜 Evolución de las Directivas en Angular (Pregunta de Entrevista Técnica)

• AngularJS (1.x Legacy): Se usaba ng-if y ng-repeat.
• Angular (v2 a v16): Se usaban directivas con asterisco: *ngIf y *ngFor.
• Angular Moderno (v17+): Se introdujo el Built-in Control Flow con arroba: {{ '@if' }} y {{ '@for' }}. Es más rápido, no necesita importar CommonModule para directivas básicas y se lee como JavaScript nativo.
