💡 Nota para la Clase

En PHP o Spring Boot teníamos composer.json o pom.xml. En Angular, package.json cumple esa misma función: declara qué versión estamos usando y qué librerías necesita nuestro hechizo para funcionar.

📦 Metadatos Generales

name: Identificador único del proyecto (ej. angular-colegio-magico).

version: Versión actual de los encantamientos (semver, ej. 0.0.1).

private: Evita publicaciones accidentales al registro público de npm.

🌲 La Regla de Oro del Bosque

La carpeta node_modules/ es donde npm descarga físicamente el código de las dependencias. ¡NUNCA se sube a Git! Pesa cientos de megabytes. Para revivirla en cualquier máquina solo corremos npm install.
